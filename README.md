# STM32 MLX90614 Temperature Display

Projeto utilizando STM32 NUCLEO-G474RE com sensor infravermelho MLX90614 e display.

## Recursos
- Comunicação I2C
- Leitura de temperatura
- Exibição em display
- STM32 HAL

## Estrutura
- `firmware/` → Código STM32
- `docs/imagens/` → Fotos do projeto
- `docs/video/` → Vídeos de funcionamento
- `docs/testes/` → Arquivos auxiliares

## Hardware
- STM32 NUCLEO-G474RE
- Sensor MLX90614
- Display

## IDE utilizada
STM32CubeIDE
